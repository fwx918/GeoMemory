# 时迹 ChronoTrace

> 站在现在，看见从前。

时迹是一款基于位置与历史数据的时空探索 Web App。打开地图、选择任意地点，时迹就能带你穿越时间，发现这片土地在不同年代的模样、名字、居民、建筑与故事。

这是一个**功能性 MVP**：完整实现了五大核心功能的交互体验，**全部数据为内置的模拟史料，无需任何 API Key、无任何网络请求，可完全离线运行**。

## ✨ 核心功能

| Tab | 功能 | 说明 |
| --- | --- | --- |
| 🗺️ 时空地图 | Time-Space Map | 拖动时间轴在 2026 / 2000 / 1950 / 1900 / 1800 / 更早 之间切换，观察同一地点的程式化地图随时代平滑变形 |
| 📖 此地从前 | This Place Before | 输入现代地址，生成地名由来、历史变迁、关键人物、标志事件与古今对比 |
| 🏛️ 古今对照 | Past-Present Overlay | 拖动滑块叠加对比同一地点的最古与最今地图，可切换水体 / 海岸线 / 城市范围等图层 |
| 🤖 AI 时空导游 | AI Time Guide | 像与历史学家聊天一样提问，导游结合该地史料作答（基于关键词 + 年代匹配的模拟引擎） |
| 🚶 发现身边故事 | Discover Nearby | 调用浏览器定位（拒绝/离线时自动回退到模拟位置），列出附近值得了解的历史地点 |

## 🗺️ 关于地图

为保证 **100% 离线可用**，地图未使用 Leaflet/OSM 等需要联网拉取瓦片的方案，而是采用**自绘的程式化分层 SVG 地图**：每个地点的每个时代都提供一套 SVG 几何（水体、海岸线、城市范围、道路堤岸、地标），时代切换时通过 CSS 过渡平滑变形。这既保证了离线，也让「古今对照」（如新加坡填海造地、西湖湖岸演变）真正可视化。地图为示意性的，并非地理精确。

## 🧱 技术栈

- **构建**：Vite + React 18 + TypeScript
- **样式**：Tailwind CSS（移动优先，宣纸 + 印章红配色）
- **路由**：react-router-dom（HashRouter）
- **状态**：单一 `AppContext`（当前地点 / 当前时代 / 对话历史），无 Redux

## 📁 目录结构

```
src/
  types/      数据模型
  data/       种子史料 + 时代定义 + AI 问答规则 + 选择器
  context/    全局状态 AppContext
  hooks/      useAiGuide（模拟 AI 引擎）/ useGeolocation
  components/ layout · map · timeline · overlay · chat · common
  features/   五大功能各一个页面
```

## 🚀 本地运行

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览生产构建
npm run typecheck  # 仅类型检查
```

## ✅ 验证

1. 🗺️ 拖动时间轴 2026 → 1800 → 更早，观察地图变形与时代卡片更新。
2. 📖 输入 `上海市南京东路`，查看地名由来 / 人物 / 事件 / 古今对比。
3. 🏛️ 切到新加坡丹戎巴葛，拖动滑块看海岸线填海变化。
4. 🤖 提问「这里500年前是什么？」「这里有哪些名人？」，获得导游口吻的回答。
5. 🚶 允许/拒绝定位，查看附近历史地点，点击可跳转到对应地图。

**离线验证**：打开 DevTools → Network → 勾选 Offline → 刷新，应用功能完好、无任何失败请求。

## 📚 内置地点

- **杭州西湖** — 湖岸与苏堤/白堤的千年演变
- **上海南京东路** — 从城北滩涂到远东第一商街
- **新加坡丹戎巴葛** — 从渔村海岬到填海而成的 CBD

> 时迹不是带你去另一个地方，而是带你重新认识你所在的地方。
