# 时迹 ChronoTrace

> 站在现在，看见从前。

时迹是一款基于位置与历史数据的时空探索 Web App。打开地图、选择任意地点，时迹就能带你穿越时间，发现这片土地在不同年代的模样、名字、居民、建筑与故事。

这是一个**功能性 MVP**：完整实现了五大核心功能的交互体验，**全部数据为内置的模拟史料，无需任何 API Key、无任何网络请求，可完全离线运行**。

## ✨ 核心功能

| Tab | 功能 | 说明 |
| --- | --- | --- |
| 🗺️ 时空地图 | Time-Space Map | 拖动时间轴切换年代（各地点提供自己拥有史料的年代），底图不变、叠加层随时代淡入切换 |
| 📖 此地从前 | This Place Before | 输入现代地址，生成地名由来、历史变迁、关键人物、标志事件与古今对比 |
| 🏛️ 古今对照 | Past-Present Overlay | 拖动滑块叠加对比同一地点的最古与最今地图，可切换水体 / 海岸线 / 城市范围等图层 |
| 🤖 AI 时空导游 | AI Time Guide | 像与历史学家聊天一样提问，导游结合该地史料作答（基于关键词 + 年代匹配的模拟引擎） |
| 🚶 发现身边故事 | Discover Nearby | 调用浏览器定位（拒绝/离线时自动回退到模拟位置），列出附近值得了解的历史地点 |

## 🗺️ 关于地图

四个地点全部采用**真实地理地图（GeoMap）**，且**无需联网拉取瓦片、可离线运行**：使用真实经纬度的行政边界 / 海岸线 / 河流 / 湖泊（来自阿里 DataV、开源世界国界等 GeoJSON，经 Douglas-Peucker 精简后内置），渲染时按真实长宽比投影到视图，形状与真实地理一致；地标按真实经纬度落点。时代切换时，底图（边界、河湖）保持不变，叠加层（古城墙、铁路、历史海岸线、地标）随时代变化。

- **淮南**：真实市域边界 + 淮河 + 瓦埠湖/高塘湖/焦岗湖 + 八公山
- **杭州西湖**：真实湖体轮廓 + 苏堤/白堤 + 钱塘江 + 西山
- **上海南京东路**：真实市域边界 + 黄浦江/苏州河
- **新加坡丹戎巴葛**：真实主岛海岸线 + 1800 历史海岸线（虚线，直观对比填海造地）

> 四个地点统一由 `GeoMap` 渲染；切换年代时叠加层以淡入过渡呈现。瓦片方案（Leaflet/OSM）因需联网且无历史底图而未采用。

## 🧱 技术栈

- **构建**：Vite + React 18 + TypeScript
- **样式**：Tailwind CSS（响应式，宣纸 + 印章红配色）
  - **手机端**：居中窄列 + 底部 Tab 导航
  - **桌面端（≥1024px）**：左侧边栏导航 + 宽屏多栏布局（地图与文字左右并排、卡片双栏）
- **路由**：react-router-dom（HashRouter）
- **状态**：单一 `AppContext`（当前地点 / 当前时代 / 对话历史），无 Redux

## 📁 目录结构

```
src/
  types/      数据模型
  data/       种子史料 + 时代定义 + AI 问答规则 + 选择器
  context/    全局状态 AppContext
  hooks/      useAiGuide（模拟 AI 引擎）/ useGeolocation
  components/ layout · map · timeline · overlay · chat · common
  features/   五大功能各一个页面
```

## 📚 内置地点（均为真实地理地图）

- **杭州西湖**（真实化试点）— **11 档朝代级时间轴**（秦汉六朝→隋→唐→吴越→两宋→元明→清→民国→当代），真实 OSM 西湖水体（508 点 20 环，含三岛）+ Natural Earth 钱塘江 + 运河/山体/城墙；每个时代有专属地理要素（南宋临安城墙、民国沪杭铁路、当代地铁）
- **淮南** — 楚都寿春 / 淮南王刘安与八公山豆腐 / 淝水之战 / 近代煤电之都
- **上海南京东路** — 从城北滩涂到远东第一商街
- **新加坡丹戎巴葛** — 从渔村海岬到填海而成的 CBD

> 时迹不是带你去另一个地方，而是带你重新认识你所在的地方。
